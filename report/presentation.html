Problem Statement

Main memory is significantly slower than the processor. A small, fast cache exploits spatial and temporal locality to reduce the average cost of memory accesses.

Objective: Design, verify, and evaluate a parameterized direct-mapped cache in Verilog.

Cache Organisation

cache_controller — Mealy FSM: IDLE → REFILL → RESPOND
data_ram — 64 lines × 16 B = 8192 data bits
tag_ram — 64 × 22-bit tags = 1408 bits
valid_ram — 64 × 1-bit, bulk reset
addr_decoder — Splits address → tag, index, offset
tag_comparator — hit = valid & (stored_tag == req_tag)

Key Design Decisions

  • ✓ Blocking — one request at a time
  • ✓ Read-only baseline — write-through optional
  • ✓ 1-cycle hit — Mealy outputs, async RAM read
  • ✓ Valid bit — prevents false hits on uninitialised tags
  • ✓ Tag + valid set with last word — no partial lines visible
  • ✓ 82% of area is data_ram (8192 flip-flops)

AMAT Calculation

AMAT = hit_time + miss_rate × miss_penalty
AMAT = 1 + miss_rate × 21

Miss Penalty Derivation

miss_latency = W × (L + 1) + 2
            = 4 × (4 + 1) + 2
            = 22 cycles
miss_penalty = 22 − 1 = 21 cycles
W = 4 words/block, L = 4 (MEM_LATENCY)

Worked Example: Sequential Trace

Miss rate = 25% (1024 / 4096)
AMAT = 1 + 0.25 × 21
     = 1 + 5.25
     = 6.25 cycles
Best: Loop → 1.164   Worst: Stride → 22.000

Conclusion & Future Work

Key Findings

  • ✦ Spatial locality yields 75% hit ratio (sequential, row-major)
  • ✦ Temporal locality achieves 99.2% (loop fits in cache)
  • ✦ Column-major traversal → 100% conflict misses
  • ✦ AMAT ranges from 1.16 to 22.0 cycles
  • ✦ Larger blocks improve spatial reuse but increase miss cost
  • ✦ data_ram dominates area (82%+ of generic cells)

Future Work

  • → Set associativity (2-way, 4-way)
  • → Alternative replacement policies (LRU, PLRU)
  • → Write-back / write-allocate
  • → Application-derived traces
  • → Multi-level cache hierarchy
  • → Power estimation

"The highest hit ratio is not automatically the lowest AMAT — evaluate the miss cost as well as the miss frequency."
